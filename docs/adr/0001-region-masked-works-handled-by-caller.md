# 区域屏蔽作品由调用方依据 locationMask 判断，库内不自动降级

pixiv 会按访问者所在地区屏蔽部分作品：详情端点仍返回 200 并在 `locationMask` 标出该状态，而页端点返回 404。库选择不替调用方处理这种情况——`FetchPages` 不做「先查详情端点、命中屏蔽就跳过」的内部降级，只在详情记录上暴露 `locationMask`，由调用方决定是否发起页请求。

考虑过的替代方案是让 `FetchPages` 内部自动降级。否决理由：区域屏蔽作品的页端点本就无数据可取，降级没有可降的内容，却会为每个普通作品平白增加一次请求。此外 404 响应体不携带可区分区域屏蔽的信息（`message` 为空），库层无从判断；唯一的信息来源是详情端点，而那只该由已经持有该信息的调用方来读。
